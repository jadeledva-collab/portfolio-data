Python Seaborn / Matplotlib Analyse Bivariée Superstore Dataset

📊 Projet 4 : Tests Statistiques & Écarts entre Départements

Problématique métier : Analyser les écarts de performance entre départements en explorant les relations entre variables qualitatives (départements, satisfaction) et quantitatives (scores de performance, heures travaillées).

Objectif : Valider les différences observées en appliquant des tests statistiques adaptés.

Python (SciPy) Tests Statistiques ANOVA / Khi-deux Employee Performance Evaluation

Tests & Validation

  • Relations qualitatives : Khi-deux, V de Cramer, T de Tschuprow, Fisher Exact Test.
  • Comparaison de moyennes : ANOVA, Kruskal-Wallis, Test t de Student, Wilcoxon.
  • Normalité & Variances : Shapiro-Wilk, Levene, Bartlett, Kolmogorov-Smirnov.
🔗 Voir le projet (Google Colab)

Conclusions & Recommandations

  • Validation de l'indépendance entre la satisfaction et le département d'appartenance.
  • Mise en place de sessions de calibrage managérial pour harmoniser les critères d'évaluation.
  • Démonstration de l'absence d'impact statistique des heures supplémentaires sur la performance réelle.
