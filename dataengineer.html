Scraping & Pipeline ETL (Trustpilot Reviews)

ETL & Automatisation
Contexte & Objectifs

Conception d'une solution pour extraire, nettoyer et structurer les avis clients de concurrents depuis des sites web afin de mener des analyses comparatives sur des produits similaires.

Pipeline Technique & Étapes Clés
  • Scraping : Identification et extraction des avis via BeautifulSoup et gestion des structures HTML par sélecteurs CSS.
  • Transformation : Nettoyage des données (suppression des balises HTML, gestion des doublons et formatage du texte).
  • Stockage : Conception d'une base de données relationnelle SQLite et insertion automatique des flux.
  • Automatisation : Orchestration des tâches de traitement via un pipeline quotidien Apache Airflow.

Système de Collecte API & Stockage SQL (Météo Tourisme)

API Integration & SQL
Contexte & Objectifs

Automatisation de la collecte de données météorologiques en temps réel via une API publique pour différentes destinations touristiques, facilitant l'intégration de prévisions dans des applications mobiles[cite: 15].

Pipeline Technique & Étapes Clés
  • Connexion API : Authentification sécurisée et requêtes HTTP GET vers l'API OpenWeather à l'aide de la bibliothèque requests[cite: 15].
  • Traitement JSON : Récupération, nettoyage, normalisation des données et gestion des valeurs manquantes[cite: 15].
  • Modélisation SQL : Conception d'une base relationnelle normalisée (tables destination et weather_log liées par clé étrangère) sous SQLite[cite: 15].
  • Insertion robuste : Intégration sécurisée des relevés de température et d'humidité[cite: 15].
