Segmentation clients et clustering non supervisé

Problématique métier : Regrouper les clients d'un centre commercial en segments homogènes pour adapter les campagnes marketing ciblées.

Objectif : Segmenter la clientèle en fonction de leurs revenus et de leurs scores de dépenses sans étiquettes préalables.

Python K-Means / CAH Clustering Mall Customers Dataset

Compétences et méthodologie

  • Utilisation de la méthode du coude (Elbow Method) pour déterminer k.
  • Algorithmes de clustering : K-Means, Clustering Hiérarchique (CAH).
  • Évaluation de la qualité des clusters via le score de silhouette.

Résultats et recommandations

  • Identification de personae clés (ex: clients à hauts revenus et forte dépense).
  • Aide à la décision marketing pour cibler les programmes de fidélité.
  • Visualisation claire des frontières de clusters par projection spatiale.

Modèles de régression et déploiement API (Advertising)

Contexte et objectifs : Construction, entraînement et optimisation de modèles de régression prédictifs, suivis de l'industrialisation complète du modèle via le développement d'une API et sa containerisation.

Problématique marketing : Comment prédire les ventes futures d'une entreprise en fonction de ses investissements publicitaires (budgets TV, Radio et Presse) ?

Python Scikit-learn XGBoost FastAPI Docker Joblib

Modélisation et ML

  • Comparaison d'algorithmes : Évaluation de modèles de régression linéaire (Ridge, Lasso, ElasticNet) et de modèles ensemblistes (Random Forest, XGBoost, LightGBM, CatBoost).
  • Sélection et sérialisation : Choix du modèle XGBoost (XGBRegressor) sauvegardé via joblib (xgboost_advertising_model.pkl).

Pipeline MLOps

  • Développement API (app.py) : Création d'un service web sous FastAPI avec un endpoint de prédiction en temps réel (/predict).
  • Containerisation (Dockerfile) : Configuration d'un environnement isolé (image Python slim, dépendances via requirements.txt) pour le Cloud.
