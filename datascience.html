Analyse d'A/B Testing & Prise de Décision

Expérimentation
Contexte & Objectifs

Mise en place d'une expérimentation contrôlée pour comparer deux versions d'une landing page (ancienne vs nouvelle) afin d'optimiser les performances e-commerce et d'analyser les résultats avec rigueur statistique[cite: 5].

Problématique & Dataset

Quelle version d'une landing page convertit le mieux les utilisateurs ?[cite: 5] Traitement de plus de 290 000 lignes de trafic web issues de Kaggle (Dataset A/B Testing)[cite: 5].

Compétences & Résultats Clés
  • Nettoyage et structuration de grands volumes de données web via Pandas.
  • Réalisation d'un Z-test des proportions (via Statsmodels / Scipy)[cite: 5].
  • Obtention d'une p-value de 0.1897 ( > 0.05), démontrant que la différence observée (12.04% vs 11.88%) n'est pas statistiquement significative[cite: 5].
  • Recommandation métier : ne pas déployer la nouvelle page en production pour capitaliser sur d'autres axes d'optimisation[cite: 5].
Python Pandas Statsmodels Scipy Matplotlib / Seaborn

Modèles de Régression Avancés & Déploiement API

Machine Learning & MLOps
Contexte & Objectifs

Construction, comparaison et optimisation de modèles de régression pour prédire des valeurs continues (prédiction des ventes publicitaires et estimation de prix immobiliers)[cite: 5].

Problématiques & Datasets
  • Marketing : Prédire les ventes en fonction des budgets TV, radio et presse (Advertising Sales Dataset)[cite: 5].
  • Immobilier : Prédire le prix de vente d'une maison selon ses caractéristiques (House Prices Techniques)[cite: 5].
Compétences & Implémentation
  • Évaluation comparative de multiples algorithmes : Régression Linéaire, Ridge, Lasso, ElasticNet, et modèles basés sur les arbres (Random Forest, XGBoost, LightGBM, CatBoost)[cite: 5].
  • Sérialisation et sauvegarde du modèle de pointe (`XGBRegressor`) via Joblib[cite: 6, 9].
  • Développement d'une API de scoring en temps réel avec FastAPI (`app.py`)[cite: 5, 6].
  • Containerisation du modèle et de l'API via Docker (`Dockerfile`) pour faciliter le déploiement cloud[cite: 5, 7, 8].
Python Scikit-Learn XGBoost FastAPI Docker
