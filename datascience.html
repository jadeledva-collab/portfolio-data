Projet 2 : A/B Testing – Optimisation d'une Landing Page

Expérimentation
Contexte & Objectifs

L’A/B testing est une méthode utilisée pour comparer deux versions d'un produit ou d'un service afin de déterminer laquelle est la plus performante. Ce projet met en place une expérimentation contrôlée pour comparer deux groupes et analyser les résultats à l'aide de statistiques pour choisir la version gagnante.

Problématique

Marketing : Quelle version d’une landing page convertit le mieux les utilisateurs ?

Compétences & Résultats Clés
  • Nettoyage et préparation de plus de 290 000 lignes de données de trafic.
  • Réalisation de tests statistiques (Z-test des proportions) pour évaluer la significativité.
  • Visualisation claire des résultats pour orienter la décision (recommandation de ne pas déployer la nouvelle page suite à une p-value de 0.1897).
Python Pandas Scipy Statsmodels Matplotlib / Seaborn

Projet 4 : Régression & Déploiement API (Advertising)

Machine Learning & MLOps
Contexte & Objectifs

La régression permet de prédire des valeurs continues. Ce projet consiste à construire des modèles de régression, à comparer et optimiser leurs performances, puis à industrialiser le modèle.

Problématique

Marketing : Comment prédire les ventes futures en fonction des budgets publicitaires ?

Compétences & Implémentation technique
  • Modélisation de régression : Régression Linéaire (simple et multiple), Ridge, Lasso, et ElasticNet.
  • Modèles basés sur les arbres : Arbre de décision, Random Forest, AdaBoost, XGBoost (modèle retenu et sérialisé via `joblib`), LightGBM et CatBoost.
  • Déploiement d'une API : Mise en place d'une API sous FastAPI (`app.py`) pour fournir des prédictions de ventes en temps réel.
  • Containerisation : Utilisation de Docker (`Dockerfile` et `requirements.txt`) pour faciliter la mise en production.
Python Scikit-learn XGBoost FastAPI Docker
