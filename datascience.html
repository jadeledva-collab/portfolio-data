Projet 2 : A/B Testing – Optimisation d'une Landing Page

Expérimentation & Statistiques
Contexte & Objectifs

Mise en place d'une expérimentation contrôlée pour comparer deux versions d'une landing page afin de déterminer laquelle est la plus performante. Ce projet utilise l'A/B testing, une méthode essentielle en marketing pour optimiser les taux de conversion[cite: 5].

Problématique Marketing

Quelle version d'une landing page (contrôle vs. traitement) convertit le mieux les utilisateurs ?[cite: 5]

Méthodologie & Résultats Clés
  • Nettoyage et filtrage de plus de 290 000 logs de trafic web pour isoler les données pertinentes[cite: 5].
  • Analyse statistique via un Z-test des proportions pour évaluer la significativité des résultats[cite: 5].
  • Conclusion : Le test a révélé une p-value de 0.1897 (supérieure au seuil de 0.05). La différence de conversion (12.04% pour l'ancienne page contre 11.88% pour la nouvelle) n'étant pas statistiquement significative, la recommandation est de ne pas déployer la nouvelle version[cite: 5].

Projet 4 : Régression & Déploiement API (Sales Prediction)

Machine Learning & MLOps
Contexte & Objectifs

Construction et optimisation de modèles de régression pour prédire des valeurs continues. L'objectif final est l'industrialisation du meilleur modèle via une API containerisée[cite: 5, 8].

Problématique Marketing

Comment prédire les ventes futures d'une entreprise en fonction de ses investissements publicitaires (budgets alloués à la TV, la Radio et la Presse) ?[cite: 5]

Modélisation & Déploiement
  • Comparaison de modèles : Évaluation de plusieurs algorithmes allant de la régression linéaire avec régularisation (Ridge, Lasso, ElasticNet) jusqu'aux modèles ensemblistes basés sur les arbres (Random Forest, AdaBoost, LightGBM, CatBoost)[cite: 5].
  • Sélection : C'est le modèle XGBoost (`XGBRegressor`) qui a été retenu pour ses performances et sauvegardé via `joblib`[cite: 5, 6, 9].
  • Mise en production (API) : Développement d'une interface de prédiction en temps réel avec FastAPI (`app_2.py`)[cite: 5, 10, 12].
  • Containerisation : Création d'un environnement isolé et reproductible via Docker pour faciliter le déploiement sur le cloud[cite: 5, 11].
