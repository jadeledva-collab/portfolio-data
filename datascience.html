A/B Testing – Optimisation d'une Landing Page

Expérimentation & Statistiques
Contexte & Objectifs

Mise en place d'une expérimentation contrôlée pour comparer deux versions d'une landing page afin de déterminer laquelle est la plus performante. Ce projet utilise l'A/B testing, une méthode essentielle en marketing pour optimiser les taux de conversion.

Problématique Marketing

Quelle version d’une landing page (contrôle vs. traitement) convertit le mieux les utilisateurs ?

Méthodologie & Résultats Clés
  • Nettoyage et filtrage de plus de 290 000 lignes de trafic web pour isoler les données pertinentes.
  • Analyse statistique via un Z-test des proportions pour évaluer la significativité des résultats.
  • Conclusion : Le test a révélé une p-value de 0.1897 (supérieure au seuil de 0.05). La différence de conversion (12.04% vs 11.88%) n'étant pas statistiquement significative, la recommandation est de ne pas déployer la nouvelle version.

Modèles de Régression & Déploiement API (Advertising)

Machine Learning & MLOps
Contexte & Objectifs

Construction, entraînement et optimisation de modèles de régression prédictifs, suivis de l'industrialisation complète du modèle via le développement d'une API et sa containerisation.

Problématique Marketing

Comment prédire les ventes futures d'une entreprise en fonction de ses investissements publicitaires (budgets TV, Radio et Presse) ?

Modélisation & Pipeline MLOps
  • Comparaison d'algorithmes : Évaluation de modèles de régression linéaire (Ridge, Lasso, ElasticNet) et de modèles ensemblistes (Random Forest, XGBoost, LightGBM, CatBoost).
  • Sélection & Sérialisation : Choix du modèle XGBoost (`XGBRegressor`) pour ses performances optimales, exporté et sauvegardé au format binaire via `joblib` (`xgboost_advertising_model.pkl`)[cite: 6, 9].
  • Développement de l'API (`app.py`) : Création d'un service web sous FastAPI proposant un endpoint de prédiction en temps réel (`/predict`) basé sur les budgets publicitaires[cite: 6].
  • Containerisation (`Dockerfile`) : Configuration d'un environnement d'exécution isolé (image Python slim, installation des dépendances via `requirements.txt`) prêt pour le déploiement Cloud[cite: 7, 8].
