A/B Testing – Optimisation d'une landing page

Contexte et objectifs : Mise en place d'une expérimentation contrôlée pour comparer deux versions d'une landing page afin de déterminer laquelle est la plus performante. Ce projet utilise l'A/B testing, une méthode essentielle en marketing pour optimiser les taux de conversion.

Problématique marketing : Quelle version d’une landing page (contrôle vs. traitement) convertit le mieux les utilisateurs ?

Python Pandas Scipy (Stats) Statsmodels Matplotlib / Seaborn

Traitement des données

  • Nettoyage et filtrage de plus de 290 000 lignes de trafic web pour isoler les données pertinentes.

Analyse & Résultats Clés

  • Analyse statistique via un Z-test des proportions pour évaluer la significativité.
  • Conclusion : p-value de 0.1897 (> 0.05). La différence n'est pas significative, recommandation de ne pas déployer la nouvelle version.

Modèles de régression et déploiement API (Advertising)

Contexte et objectifs : Construction, entraînement et optimisation de modèles de régression prédictifs, suivis de l'industrialisation complète du modèle via le développement d'une API et sa containerisation.

Problématique marketing : Comment prédire les ventes futures d'une entreprise en fonction de ses investissements publicitaires (budgets TV, Radio et Presse) ?

Python Scikit-learn XGBoost FastAPI Docker Joblib

Modélisation & ML

  • Comparaison d'algorithmes : Évaluation de modèles de régression linéaire (Ridge, Lasso, ElasticNet) et de modèles ensemblistes (Random Forest, XGBoost, LightGBM, CatBoost).
  • Sélection & Sérialisation : Choix du modèle XGBoost (XGBRegressor) sauvegardé via joblib (xgboost_advertising_model.pkl).

Pipeline MLOps

  • Développement API (app.py) : Création d'un service web sous FastAPI avec un endpoint de prédiction en temps réel (/predict).
  • Containerisation (Dockerfile) : Configuration d'un environnement isolé (image Python slim, dépendances via requirements.txt) pour le Cloud.
